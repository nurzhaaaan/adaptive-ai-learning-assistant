# Project Specification

## Title
Development of an AI-Based Adaptive Learning Assistant for University Students

## Problem
Traditional LMS platforms usually provide the same content sequence to every student. Students who struggle with a topic may receive material that is too difficult, while stronger students may be forced to repeat simple content.

## Proposed solution
The system tracks quiz results and topic mastery for each student. It assigns an adaptive difficulty and generates a personalized recommendation after every quiz. A context-aware AI tutor can explain the same topic differently for Beginner, Intermediate and Advanced students.

## Main modules

- Authentication
- Courses and topics
- Adaptive quizzes
- Topic mastery
- Recommendation engine
- Analytics
- AI Tutor

## Novelty
The project combines an adaptive learning engine with a contextual AI tutor in a university-oriented learning environment. The tutor is not isolated from the learning system: its response context includes the current topic, mastery score and calculated student level.
